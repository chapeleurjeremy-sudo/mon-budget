# Mon Budget V1.1

Application web de gestion budgétaire personnelle.

## V1.1
- Vue détaillée de chaque enveloppe
- Liste des achats par enveloppe
- Ajout, modification et suppression des achats
- Date, description, montant et enveloppe
- Calcul automatique du budget restant
- Revenus et épargne modifiables
- Création/modification/suppression d'enveloppes
- Export/import JSON
- Stockage local du navigateur
- Pas de connexion bancaire

## GitHub Pages
1. Crée un dépôt public, par exemple `mon-budget`.
2. Mets `index.html`, `manifest.json` et `README.md` à la racine.
3. Settings → Pages.
4. Source : Deploy from a branch.
5. Branch : `main`, dossier : `/ (root)`.
6. Save.
7. Ouvre l'adresse GitHub Pages fournie.

Les données sont locales au navigateur. Utilise Exporter pour faire une sauvegarde.

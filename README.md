# Mon Budget V1
Application web de budget personnel, paramétrable et sans connexion bancaire.

## Fonctionnalités
- revenu mensuel modifiable
- objectif d'épargne modifiable
- enveloppes personnalisables
- ajout et historique des dépenses
- budget restant et rythme quotidien indicatif
- sauvegarde locale dans le navigateur
- export/import JSON
- compatible GitHub Pages

## GitHub Pages
Déposer `index.html` et `manifest.json` à la racine du dépôt puis Settings > Pages > Deploy from branch > main > root.

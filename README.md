# Mon Budget V1.2

Nouveautés : paiements récurrents mensuels, activation/désactivation, jour du mois, génération automatique une fois par mois, protection contre les doublons, identification des achats récurrents, export/import et migration des données V1.1.

Installation : remplacer `index.html` et `manifest.json` dans votre dépôt GitHub Pages. Les données restent dans le navigateur via localStorage.
